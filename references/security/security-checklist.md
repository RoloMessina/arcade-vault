## Checklist de seguridad básico

  - [x] RLS: Row Level Security habilitado en ambas tablas: `games` y `scores` (y `profiles`). Verificado por SQL (spec 15)
  - [x] Minimum password length — mínimo 8 caracteres (panel de Supabase + `AuthForm.tsx`, spec 15)
  - [ ] Leaked password protection — (el warning 4). **Bloqueado por el plan:** solo disponible en Supabase Pro; el proyecto es Free. El aviso del linter permanece
  - [x] Max signup rate — limitar signups por IP (anti-bot): 10 cada 5 minutos por IP (panel de Supabase → Auth → Rate Limits)
  - [x] Headers de seguridad en Next.js (`next.config.ts`): los 3 del ejemplo + `Strict-Transport-Security` + `Permissions-Policy`. Sin CSP (fuera de alcance, spec aparte)

  Ej:

```ts
const securityHeaders = [
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'X-Frame-Options', value: 'DENY' },
  { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
];

// En la config de Next.js:
headers: async () => [
  { source: '/(.*)', headers: securityHeaders }
]
```
